Cómo usar RestoOps

1. IngredientesRegistra la compra real: por ejemplo, cantidad comprada, unidad y costo total. El sistema obtiene el costo unitario automáticamente.
2. PlatosCrea cada producto y agrega cuánto usa de cada ingrediente. Define su precio de venta y, si quieres, un margen objetivo.
3. ProyecciónIndica cuántos platos quieres vender. Verás cuánto necesitas de cada ingrediente, inversión, venta y utilidad estimada.
4. Ventas realesAl finalizar o durante el día registra las unidades vendidas. El dashboard calcula costo, utilidad, margen y descuenta inventario.
5. Presupuesto y cajaRegistra ingresos, egresos y pagos pendientes. Configura límites mensuales por categoría, consulta el saldo y exporta el historial.
